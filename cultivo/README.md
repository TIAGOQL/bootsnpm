# Cultivo de ideias

Canteiro do projeto. Aqui uma ideia nasce pequena e pode virar módulo REM, página, hábito ou só pergunta boa.

## Como inserir

### 1. Rápido (no navegador)
Abra `pesquisas/cultivo-ideias.html` no painel.  
Plante a ideia ali — fica salva **só neste aparelho** (localStorage).

Estágios:
- **semente** — acabou de surgir  
- **broto** — ganhou uma frase de porquê  
- **planta** — tem próximo passo  
- **colheita** — virou algo no projeto (página, módulo, hábito)

### 2. Permanente (no repositório)
Quando a ideia merecer ficar no Git:

1. Crie `cultivo/ideias/<slug>.md` a partir do modelo `cultivo/ideias/_modelo.md`
2. Preencha título, estágio, módulo REM (se houver), nota
3. Se virar pesquisa de verdade, promova para `pesquisas/` e coloque atalho no painel
4. Commit na branch atual

### 3. Pelo Cursor
Diga: **“planta no cultivo: …”**  
O agente cria o `.md` em `cultivo/ideias/` e, se pedir, liga ao REM.
