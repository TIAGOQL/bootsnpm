# Exit

- **Estágio:** colheita
- **Módulo REM:** palavra · M0 · sinais
- **Plantada em:** 2026-08-03
- **Próximo passo:** quando a redoma apertar — achar a porta (Sinais / Pause / Win+L); exit com escolha, não de pânico

## Nota

Exit = ir para fora (latim ex + ire). Palco, porta, comando. No REM: saída não é falha — é roteiro.

## Por que importa

Toda casa precisa de porta. Sem exit, vira redoma.
