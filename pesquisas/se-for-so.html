inspeção de expressão

Se for só

Três palavras. Uma porta. Se for só açúcar — dilui. Se for só eco — não inventa. Se for só fato — age.

Forma: expressão condicional · se + for + só
Quer dizer: “caso seja meramente X” — testa se a coisa é só isso, sem resto útil
Vizinhos: diluir · xarope · eco · lição

Peças:
se — condição, não certeza
for — futuro do subjuntivo de ser: hipótese
só — meramente, apenas (cuidado: não confundir com só de solidão no ouvido)

Por que importa no REM: é o gancho curto do canteiro. “Se for só nostalgia → diluir.” “Se for só rima → não inventar biografia (eco).” “Se for só fato magro → uma linha e age.” Cabe em M0 e no guia do xarope.

Diário: completa a frase uma vez: se for só ____, então ____. Calma 1–5 ao lado.

Dois lados

Bom
Filtro rápido · evita drama · separa excesso de núcleo · cabe em baixa energia.
Ruim
Minimizar o que importa (“é só…”) · usar pra invalidar dor · fechar o laço cedo demais (M6).
Forma invertida
Letras do bloco: ós rof es. Sentido útil: se for mais — às vezes não é “só”; aí amplia, não dilui.
Com o xarope
Se for só cor → diluir.
Se for só rótulo → três colunas.
Se for só eco → ouvir a fonte.
Se for só fato → praticar a lição.

No stack REM

M0: hipótese limpa antes de otimizar.
M6: “é só amizade / é só eco” pode ser fuga — checar peito.
Sinais: se a frase vier com peito apertado, Sinais primeiro.
