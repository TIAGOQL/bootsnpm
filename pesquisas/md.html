inspeção de formato

MD

Extensão .md = Markdown. Texto simples com pouca marcação. No painel, é o núcleo de leitura ao lado do HTML.

Forma: extensão de arquivo · abreviação de Markdown
Quer dizer: texto legível por humanos e por máquinas · fácil de editar
Vizinhos: .html · .txt · Notion · Docs · papel

Origem: Markdown nasceu em 2004 (John Gruber) para escrever na web sem brigar com HTML. O arquivo termina em .md (às vezes .markdown). No GitHub, o .md vira página formatada sozinho.

Por que importa no REM: muita pesquisa tem dois lados — o .html (abre no painel, com chuva e atalho) e o .md (documento de leitura, mais completo, fácil de mexer). Ex.: valeu.html + valeu.md. Não é obrigatório; quando a ideia vira núcleo, o .md segura o texto.

Diário / cultivo: ideias em cultivo também nascem em .md. O aparelho guarda outra cópia no navegador — o Git guarda a semente no repositório.

Dois lados

.html
Face do painel — layout, links, hero, o que você abre no browser.
.md
Núcleo de leitura — origem, tabelas, fontes, texto para reler e editar.
Só HTML
Vale. Nem toda página precisa de .md. O núcleo entra quando a pesquisa engorda.
Só .md
Também vale no cultivo. Sem atalho no painel até virar página HTML.
