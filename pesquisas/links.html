inspeção de palavra

Links

Elo + destino + cuidado. Unem o painel. Não despejar chuva de URLs.

Forma: substantivo (do inglês link)
Quer dizer: ligações, atalhos, elos
Em Markdown: [texto](url)
Em HTML: <a href="…">

Origem: inglês link — elo de corrente. Na web, o anel vira clique. Sinônimos: hiperligação, atalho, ligação.

Por que importa no REM: o painel é tecido de links — cards, “← Painel”, notas no rodapé. Um elo certo = um passo (Sinais). Lista de URLs = ruído. Higiene: poucos links, texto que diz pra onde vai — não “clique aqui”.

Dois lados

Bom
Caminho curto. Liga módulo a módulo. Alívio.
Ruim
Chuva de URLs. Link quebrado. Abrir aba atrás de aba.
Regra
Não despejar lista de URLs. Preferir um elo com sentido.
Texto do link
Dizer o destino (“Cultivo”, “Diário”) — não “aqui”.
