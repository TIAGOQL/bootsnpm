# Abrir sem maçaneta

- **Pergunta:** quando falta uma maçaneta, como se abre a porta?
- **Tese:** falta o pomo, não o vão — outro gesto ainda abre

## No metal

| Modo | Como |
| --- | --- |
| Empurrar / puxar | Mão na folha, fresta, buraco do fuso |
| Fuso | Girar o mecanismo sem o pomo |
| Outro lado | Quem está dentro / maçaneta que sobrou |
| Trancada | Problema de chave — não só de maçaneta |
| Manter aberta | Cunha / peso no vão |

## No peito (REM)

Faltar a ferramenta habitual ≠ ficar do lado de fora. = outro modo: corpo, bater, pedir, entreabrir.

Se a maçaneta só sabia fechar, a ausência pode deixar a porta **mais aberta** — se ninguém trancar.

## No REM

- Higiene: improviso com dose
- Sinais: mão na madeira
- Diário: abri como — ou só travei?
