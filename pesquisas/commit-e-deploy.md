# Commit e deploy

Inspeção de palavra. 2026-08-04.

## Commit
Inglês: *to commit* — comprometer, entregar, registrar.
No Git: gravar um ponto no histórico. Mensagem + mudança. Ainda não é o site público.

## Deploy
Inglês: *to deploy* — colocar em posição, enviar para o campo.
No painel: publicar. Aqui: GitHub Actions em `main` → Pages.

## Ordem
1. Commit (marcar)
2. Push (enviar o histórico)
3. Deploy (página sobe se `main` + Pages = GitHub Actions)

## No REM
- Commit ≈ [Diário](diario-rem.html): marcar o dia sem sumir
- Deploy ≈ sair do aparelho — o outro vê
- Se a cabeça pesou: [Sinais](sinais.html). Commit local. Deploy depois.
- Settings → Pages → Source: **GitHub Actions** (uma vez)
