# Kill

Documento de leitura. Registro da pesquisa sobre a palavra.  
Data: 2026-08-04.

---

## O que a palavra é

**Kill** é verbo (e, por extensão, substantivo) em **inglês**.

Pelo nome: quatro letras · ataque consonantal no **K** · soam seco.

No núcleo: **fazer morrer** · **causar a morte**.

Em português, o vizinho direto é **matar**.

Antônimos úteis: **spare** (poupar) · **save** (salvar) · **heal** (curar) · **nurture** (nutrir).  
Em português: **poupar** · **salvar** · **curar** · **cuidar**.

---

## Origem

A história é **obscura** — o Oxford e o Wikcionário não fecham uma única linha limpa.

O que se sabe com segurança:

1. Chega ao inglês médio como *killen* / *kyllen* — sentido antigo também de **bater**, **golpear**, **ferir**.
2. Pode ligar-se a um inglês antigo não atestado *\*cyllan*, da raiz indo-europeia ligada a **lançar / atingir / ferir**.
3. Às vezes é aproximado de *cwellan* (inglês antigo: matar, executar) — que sobreviveu no inglês moderno como **quell** (“sufocar, fazer cessar, acalmar à força”).
4. A identificação simples *kill* = forma antiga de *quell* é **errada** (já o Century Dictionary avisava). São parentes de sombra, não a mesma palavra.

Resumo da origem: **golpe que cessa** — e, no uso moderno, o cessar mais duro: a morte.

## Camadas de uso (filtrar pelo nome)

A mesma grafia **Kill** muda de peso conforme o contexto:

| Camada | Exemplo | Peso |
| --- | --- |
| **Literal** | cause death | máximo — violência real |
| **Técnica** | *kill a process* · *kill switch* | médio — parar um sistema |
| **Tempo** | *kill time* | leve — gastar espera |
| **Êxito** | *kill it* (arranjar bem) | leve — gíria de performance |
| **Humor** | *that kills me* (me mata de rir) | leve — hipérbole |
| **Jogo** | *get a kill* | fictício — ainda ecoa o literal |

O nome é o mesmo. O risco muda. Por isso a inspeção: **ler a camada antes de repetir a palavra**.

## Por que a palavra importa

1. **É curta e dura** — cabe num grito, num título, num comando. Sinal forte.
2. **Costuma afastar** — no sentido literal, é palavra de ruptura máxima.
3. **Vaza para o figurado** — processo, tempo, performance. O literal cola no fundo mesmo quando a intenção é leve.
4. **Tem um primo útil** — **quell**: fazer cessar / acalmar. No REM, muitas vezes o que se quer é *quell* (baixar o tom), não *kill* (apagar a pessoa).

Sinais são palavras. Esta, no núcleo, **afasta**. Nas camadas leves, ainda carrega cheiro do núcleo. Filtrar.

## O bom e o ruim no mesmo nome

| Lado | Sentido |
| --- | --- |
| **Bom (figurado cuidadoso)** | Encerrar um processo travado; *kill switch* de segurança; humor consciente |
| **Ruim** | Ameaça · violência · discurso que “mata” o outro na conversa · autoagressão verbal |
| **Confusão** | Usar *kill* de jogo/gíria como se o literal não ecoasse; misturar *kill* com *quell* |

No REM: quando a cabeça pesa, preferir **cessar** · **baixar** · **higiene** · **dose**. Reservar **Kill** para inspeção — não para autodiálogo.

## Resumo para reler

**Kill**, pelo nome, carrega três camadas:

- **golpe / cessar** (origem obscura)
- **fazer morrer** (núcleo moderno)
- **parar / gastar / arrasar** (figurado — ainda com eco)

No painel, o trabalho é **nomear sem beber**: ver o peso, escolher a camada, e — se o que se quer é alívio — lembrar do primo **quell**.
