# Tecla Windows (Janela)

Documento de leitura. Inspeção da tecla.  
Data: 2026-08-03.

---

## O que é

A tecla com o **logo de janela** — entre Ctrl e Alt, dos dois lados da barra de espaço (em muitos PCs).

Nomes:

| Nome | Onde |
| --- | --- |
| **Windows key** / Win / ⊞ | Microsoft / Windows |
| **Tecla Janela** | Português falado (o ícone) |
| **Start** | Abre o menu Iniciar |
| **Super** | Linux / X11 / Wayland |
| **Meta** | Às vezes (Emacs, legado Unix) |

No Mac o primo é **⌘ Command**. Mesma ideia de “modificador do sistema” — atalhos da casa, não só do app.

---

## Origem

**1994** — Microsoft Natural Keyboard.  
**1995** — Windows 95: abrir o menu Iniciar. Teclados “Designed for Windows” passaram a exigir a tecla. Layout 104/105 teclas.

Antes: PC clássico (Model M 101) só tinha Ctrl, Alt, Shift.  
Mais cedo ainda: Lisp/Unix tinham **Super** e **Meta** (space-cadet, 1970s) — a Win key ocupou o espaço vazio e o Linux a mapeou como Super.

Sem a tecla: **Ctrl+Esc** ainda abre o Iniciar no Windows.

## O que faz

| Gesto | Efeito típico (Windows) |
| --- | --- |
| **Win** sozinha | Menu Iniciar / pesquisa |
| **Win+D** | Desktop (mostrar / voltar) |
| **Win+E** | Explorador de arquivos |
| **Win+L** | Travar a sessão |
| **Win+Tab** | Visão de tarefas |
| **Win+Setas** | Encaixar janelas |

No Linux: Super abre o overview / launcher — eco do Start.  
Vizinha: tecla **Menu** (☰) — menu de contexto, como o botão direito.

---

## Por que importa no REM

1. **Janela** = moldura. O que está *dentro* da janela não é o mundo inteiro.
2. **Win** = porta de casa do sistema — voltar ao painel, não ficar preso num app.
3. **Win+L** = trava: higiene de tela / pausa sem fechar tudo.
4. **Win+D** = desktop limpo — [Sinais](sinais.html): um de cada vez, sem janelas empilhadas na cabeça.

Sinais são palavras. Esta tecla é o **botão de casa do SO**.

---

## Dois lados

| Lado | Sentido |
| --- | --- |
| **Útil** | Sair do app · ver o desktop · travar · abrir o painel do sistema |
| **Ruim** | Spam de atalhos · Win acidental no jogo · achar que “janela” = só Microsoft |
| **Primo** | ⌘ no Mac · Super no Linux — mesma família de “modificador da casa” |

---

## Resumo para reler

**Tecla Windows / Janela** = modificador do sistema desde 1994.  
Abre a casa (Iniciar). Combinações movem o desktop.  
No REM: botão de voltar à base do aparelho — sem confundir a janela com o mundo.
