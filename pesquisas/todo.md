# Todo

Inspeção de palavra. 2026-08-04.

## Forma
- Adjetivo / pronome / advérbio conforme o uso
- Masculino singular de *todo/toda/todos/todas*
- Quer dizer: inteiro · cada · o conjunto

## Origem
Latim *totus* — inteiro, completo.

## Dois lados
| Lado | Sentido |
| --- | --- |
| **Útil** | Abranger o que importa (“todo o peito”, “todos os módulos”) |
| **Pesado** | Exigir o impossível (“fazer todo”, “resolver tudo agora”) |

## No REM
- [Sinais](sinais.html): um passo — não *todo* de uma vez
- [Higiene mental](higiene-mental.html): limpar o excesso de “tenho que dar conta de todo”
- [Protocolo N=1](protocolo-n1.html): semanas, não o mapa inteiro num dia
- [Esqueceremos](esqueceremos.html): soltar o que não cabe no *todo* forçado
