# Louco

Inspeção de palavra + tradução. 2026-08-04.

## Forma
- Adjetivo / substantivo · louco · louca · loucos · loucas

## Sentidos (PT)
1. **Clínico / pejorativo** — “perdeu a razão” (hoje: preferir linguagem de cuidado; a palavra pode ferir)
2. **Intensidade** — louco de raiva / de alegria; frio louco
3. **Paixão** — louco por (alguém / algo)
4. **Imprudência** — projeto louco, ideia louca

## Tradução (melhor forma por uso)

| Uso em PT | Melhor EN | Evitar quando |
| --- | --- | --- |
| paixão / gosto forte | *crazy about* · *mad about* | *insane* (soa clínico) |
| intensidade | *crazy* · *wild* · *intense* | *lunatic* (insulto) |
| raiva / fúria | *furious* · *mad* (UK: zangado também) | misturar com diagnóstico |
| sentido clínico | *mentally ill* (com cuidado) · termos clínicos específicos | *crazy/mad/insane* como rótulo de pessoa |
| insulto / pejorativo | (não traduzir pra usar) | qualquer calão de doença |

**Regra curta:** se for afeto ou intensidade → *crazy about* / *wild*. Se for [saúde mental](saude-mental.html) → não use *louco* como tradução; use termos de cuidado.

## Vizinhos
- *doido* · *maluco* — muitas vezes mais leves / coloquiais
- Provérbio: de médico e de louco… → [medico-e-louco.html](medico-e-louco.html)

## No REM
Palavra-sinal: pode unir (paixão) ou afastar (rótulo). Perto de [higiene mental](higiene-mental.html) e [Sinais](sinais.html). Perto de [Sócrates](socrates.html) — não fingir que “louco” explica tudo.
