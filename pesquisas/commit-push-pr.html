inspeção de palavras · família Git

Commit · push · PR

Gravar · enviar · pedir revisão. Depois: merge · main · deploy. Ordem importa.

Forma: três gestos do meio do fluxo Git / GitHub
Quer dizer: fechar o ciclo de uma mudança até pedir entrada
Ordem curta: commit → push → PR
Ordem completa: branch → add → commit → push → PR → merge → main → deploy

Origem: inglês técnico. Commit — entregar, confiar. Push — empurrar. PR = Pull Request — pedido de puxar o seu trabalho pra linha principal. Pull é o inverso do push: trazer o remoto pra você.

Por que importa no REM: o Diário grava no aparelho; o cultivo permanente grava no Git. Commit marca o momento. Push tira do notebook. PR abre a porta sem arrombar. Merge junta. Deploy (Pages em main) torna visível. LocalStorage do diário não vai no deploy. Vizinho: Diário, Cultivo, M0.

Três gestos (o núcleo)

Commit
Grava a mudança com mensagem. Fica na sua branch. Como “Salvar” com histórico.
Push
Envia a branch pro GitHub (origin). Sem push, ninguém vê. Sem push, não tem PR.
PR
Pull Request: “pode misturar isto na main?”. Revisão antes do site oficial. Draft = ainda rascunho.
Regra
Um passo de cada vez. Commit ≠ push ≠ merge ≠ deploy.

Família (o que faltava)

Branch
Trilho paralelo. Você trabalha fora da main pra não quebrar o painel no ar.
Add
Escolhe o que entra no próximo commit (git add). Sem add, commit vazio de intenção.
Pull
Puxar o remoto pra você. PR = pedido de pull da sua branch pra main.
Merge
Juntar de verdade. Depois do PR aprovado: a branch entra na main.
Main
Linha oficial. Aqui o site público nasce. Deploy só depois do merge nela.
Deploy
Desdobrar no ar. Neste repo: Actions (pages.yml) publica o Pages a partir de main. Uma vez: Settings → Pages → Source: GitHub Actions.
Origin / remoto
O GitHub. Push vai pra lá; pull vem de lá.
Draft
PR ainda em rascunho — campainha, mas “não misture ainda”.

Mapa do ciclo

Antes
Branch + add — escolher o trilho e o que entra.
Meio
Commit → push → PR — gravar, enviar, pedir.
Depois
Merge → main → deploy — juntar, oficializar, publicar.
Eco REM
Diário = commit local. Exportar / cultivo no Git = push. Painel no ar = deploy. Sem misturar os gestos quando a cabeça pesou.
