inspeção de palavras

Commit · push · PR

Gravar · enviar · pedir revisão. Três passos. Sem misturar.

Forma: três termos de Git / GitHub
Quer dizer: fechar o ciclo de uma mudança
Ordem: commit → push → PR · Não pule: PR sem push não existe

Origem: inglês técnico. Commit — comprometer, entregar. Push — empurrar. PR = Pull Request — pedido de puxar (juntar) o seu trabalho na linha principal.

Por que importa no REM: o Diário grava no aparelho; o cultivo permanente grava no Git. Commit é marcar o momento. Push é não deixar só no notebook. PR é abrir a porta sem forçar a entrada — alguém (ou você) revisa antes da main. Vizinho: Diário (Salvar / Exportar) e Cultivo (local × repositório).

Três passos

Commit
Grava a mudança com uma mensagem. Fica na sua branch. Como “Salvar” com histórico.
Push
Envia a branch pro GitHub. Sem push, ninguém vê. Sem push, não tem PR.
PR
Pull Request: “pode misturar isto na main?”. Revisão antes do site oficial.
Regra
Um passo de cada vez. Commit não é push. Push não é merge.
