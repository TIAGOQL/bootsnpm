inspeção de palavra

HTML

Marcação + página + vitrine. O que o navegador mostra. Par do núcleo .md.

Forma: sigla · HyperText Markup Language
Quer dizer: linguagem de marcação das páginas web
Extensão: .html
Par no painel: Markdown (.md) = núcleo · HTML = vitrine

Origem: Tim Berners-Lee, anos 1990. HyperText = texto com links · Markup = marcação · Language = regras. Você marca; o navegador desenha.

Por que importa no REM: o painel que você abre é HTML — cards, “← Painel”, inspeções. Ideia permanente nasce em .md (cultivo); atalho no painel aponta pro .html. Os dois convivem.

Sinais básicos

<h1>
Título. Como o nome da inspeção nesta página.
<p>
Parágrafo. Bloco de leitura.
<strong>
Negrito / ênfase — o miolo da frase.
<a href>
Link — elo pra outro lugar do painel.

Dois lados

Bom
Página pronta, um clique, tipografia do painel.
Ruim
Esquecer o .md de estudo; achar que só a vitrine basta.
