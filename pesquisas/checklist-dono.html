Checklist do dono

Você não precisa saber programar. Precisa usar o painel e proteger o que marca.

Todo dia (5–10 min):

  • Abrir Diário REM → marcar módulos e notas → Salvar
  • Se a cabeça pesou: Sinais ou Higiene mental (M0)
  • Opcional: ligar Tônus enquanto respira ou estuda

Toda semana (backup):

  • No Diário: Exportar JSON e guardar o arquivo num lugar seguro (Drive, pendrive, pasta backup)
  • Olhar o Protocolo N=1: em qual semana você está?
  • Se nasceu dúvida: plantar no Cultivo

Quando mostrar para alguém:

  • Mande o link do site + a frase: pesquisa N=1, dados só no aparelho
  • Peça só duas respostas: “O que você achou que era?” e “Onde travou?”
  • Anote no Cultivo. Uma mudança por vez com a IA.

Uma vez no GitHub (nome profissional):

  • No repo atual (bootsnpm): Settings → General → Repository name → renomear para painel-rem
  • Confirme Pages ainda em Source: GitHub Actions
  • O GitHub redireciona o URL antigo; atualize favoritos se quiser

Com a IA (sem se perder):

  • Uma mudança por pedido
  • Peça: “rode npm test e me mostre o resultado”
  • Se quebrar: cole o erro e diga “conserta sem inventar página nova”
