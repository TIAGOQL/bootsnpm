# Domínio

Documento de leitura. Inspeção da palavra.  
Data: 2026-08-04.

---

## O que a palavra é

**Domínio** é substantivo. Ortografia: *domínio*.

Quer dizer, no uso mais próximo daqui:

1. **Endereço de um site** — o nome que aponta para o lugar na internet.  
2. **Território / propriedade** — o que está sob um nome ou um senhorio.  
3. (menos usado neste canteiro) **domínio de um assunto** — saber fazer.

Vizinhos: endereço · site · casa · mapa · [sinais](sinais.html) · nome.

**Parecido, não é:** *demônio* — só o final *-ônio* em comum.

---

## Origem

Latim *dominium*: propriedade, senhorio (ligado a *dominus*, senhor).

Na web o sentido encolheu: **domínio** = o rótulo público do site (ex.: `tiagoql.github.io`).  
**Custom domain** = endereço comprado à parte. Opcional.

---

## Relação com demônio (e o -ônio)

Na boca quase colam: *domí-* / *demô-* + *-nio*.

| | Domínio | Demônio |
| --- | --- | --- |
| **Raiz** | latim *dominium* (senhorio) | grego *daimon* → latim *daemonium* |
| **Quer dizer** | endereço / território | espírito · figura do medo |
| **Pedaço comum** | **-ônio** (som de palavra “cheia”) | o mesmo final |
| **Começo** | **do-** = lugar / poder | **de-** = outra linhagem |

**Como separar:** se a tela disser “domínio”, é nome de lugar — não monstro. O ouvido cansado cola; o M0 descola.

---

## Forma invertida

### Letras
*domínio* invertida não vira palavra útil. *domínio* ↔ *demônio* também não é anagrama — é eco.

### Sentido útil
**Campo vazio ≠ pessoa inválida ≠ demônio.**

| Direto | Invertido prático |
| --- | --- |
| “Domain is not valid” | formulário rejeitou o texto |
| eco “demônio” | só o *-ônio* bateu |
| domínio próprio | GitHub.io já basta |
| travar na tela | voltar · Source = GitHub Actions |

---

## Por que importa no REM

1. **É nome de lugar** — não nome de pessoa nem de monstro.  
2. **Pode unir ou afastar** — “casa pronta” une; “inválido” / eco de demônio afasta.  
3. **M0** — filtrar excesso: mensagem de máquina ≠ julgamento ≠ medo colado.  
4. **Publicação** — o painel publica sem domínio comprado.

---

## O bom e o ruim

| Lado | Sentido |
| --- | --- |
| **Bom** | mapa claro; endereço de graça; saber onde o site mora |
| **Ruim** | colar “inválido” em si; colar domínio em demônio |
| **Espelho** | fato miúdo: campo / Source / Actions / só o -ônio |
| **Limite** | Sinais se apertar; leite derramado se for só peso velho |
