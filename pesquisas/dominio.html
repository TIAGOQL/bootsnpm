Domínio

Endereço do site. Território. Não é você — é o nome do lugar.

Forma: substantivo (ortografia: domínio)
Quer dizer: o endereço de um site · território · poder sobre algo
Vizinhos: endereço · site · casa · mapa · sinais · nome

Origem: latim dominium — propriedade, senhorio. Na internet ficou curto: o nome que aponta para o lugar (ex.: tiagoql.github.io).

Por que importa no REM: na publicação, “domínio inválido” fala do campo, não da pessoa. O formulário rejeita texto vazio ou estranho — não te julga. M0 = filtrar o sinal: erro de máquina ≠ erro de caráter. O painel já tem endereço de graça; domínio próprio é opcional.

Diário: domínio · o que o sistema disse __ · o que eu ouvi __ · fato miúdo __ · calma 1–5

Dois lados

Bom
Casa com nome · mapa claro · saber onde o site mora · GitHub.io sem comprar nada.
Ruim
Ler “inválido” como se fosse sobre você · travar no formulário errado · achar que falta domínio próprio.
Forma invertida
Prático: campo vazio ≠ pessoa inválida. Voltar · Source → GitHub Actions · deixar Custom domain em branco.

No stack REM

M0: limpar a leitura — o erro é do formulário.
Sinais: palavra que une (casa) ou afasta (inválido mal lido).
Mapa: domínio = onde a coisa mora, não quem você é.
M8: fora — não é protocolo clínico.
