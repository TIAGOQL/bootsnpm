Module → Módulo

Módulo — pedaço de código com nome.

Tradução: módulo — unidade de programa que se importa.

No Node: objeto Module do CommonJS. Cada arquivo require’d vira um módulo com id (caminho).

No REM: “módulo” também é M0–M8 do protocolo. Aqui no stack é outro sentido: arquivo JS no runtime. Não misturar com M4.1.
