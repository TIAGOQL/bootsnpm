# T ao contrário

Inspeção de símbolo. 2026-08-20.

Página: [t-ao-contrario.html](t-ao-contrario.html).

Sinal: **⊥** (T invertido). Par: **⊤** (T em pé, topo).

## Usos

| Uso | Quer dizer |
| --- | --- |
| Geometria | perpendicular · 90° |
| Lógica | falso · fundo · sem prova |
| Obra | viga / sapata em T invertido |
| Programa | tipo fundo (*bottom*) |
| Letra | T virado (`Ʇ`) |

## Não é

Cruz invertida. Sem culto. Sem ataque.

## No REM

Oficina do [Engenheiro Arquiteto](o-engenheiro-arquiteto.html). [Análise](analise.html) se for verdadeiro/falso. [Os dois juntos](os-dois-juntos.html) se for o par ⊤ / ⊥.
