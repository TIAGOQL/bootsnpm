# Signos · caracteres · teclado

Inspeção de palavras. 2026-08-04.

---

## As palavras, uma a uma

### Signo / signos
Do latim *signum*: marca, indício, bandeira.  
**Quer dizer:** algo que **representa** outra coisa (letra, símbolo, código).  
**No REM:** nomes do mapa — M, *, N=1, “bairro”, estágios do cultivo. Você **lê**.  
Página-mãe: [REM e signos](rem-e-signos.html).

### Sinal / sinais
Mesma raiz (*signum*), mas no uso cotidiano vira **aviso** ou **gesto**.  
**Quer dizer:** indício que pede ação (semáforo, aceno, “um gole agora”).  
**No REM:** a página [Sinais](sinais.html) — água, sol, peito… prática M0. Você **faz**.  
Não confundir com “sinais do teclado” (abaixo).

### Caractere / caracteres
Do grego *kharaktēr*: marca gravada, cunho.  
**Quer dizer:** unidade tipográfica — uma letra, um dígito, um símbolo no texto.  
**No REM:** cada tecla que vira marca no diário, no HTML, no cultivo.

### Especial / especiais
Do latim *specialis*: particular, à parte.  
**Quer dizer:** que não é o caso “comum” (A–Z, 0–9).  
Junta-se a *caracteres* → **caracteres especiais**.

### Teclado
Do *tecla* + *-ado*: o conjunto de teclas.  
**Quer dizer:** superfície onde os caracteres nascem no aparelho.  
É a fábrica física dos signos digitais do painel.

### Caracteres especiais
**Forma:** caracteres + especiais.  
**Quer dizer:** marcas fora do alfabeto “simples” e dos dígitos:  
`* # @ ! ? / \ | & % $ + = ~ ^ < > { } [ ] ( ) " ' \` ´ ¨ Ç` … e afins.  
Muitos pedem `Shift`, `AltGr` ou tecla morta.

### Sinais do teclado
**Forma:** sinais + do + teclado.  
**Quer dizer:** os mesmos caracteres especiais, vistos como **sinais** na superfície das teclas — o desenho que você reconhece antes de digitar.  
Linguagem de informática / digitação; **não** é a página Sinais (gesto M0).

## Relação entre as camadas

```
teclado
  → sinais do teclado (o desenho na tecla)
    → caracteres especiais (o que entra no texto)
      → signos (o que o REM lê como nome/código)
```

À parte, em paralelo:

```
corpo / dia
  → sinais (gesto M0: água, sol, peito…)
```

| Camada | Palavra | Ação |
| --- | --- | --- |
| Corpo | sinais | fazer |
| Tecla | sinais do teclado | reconhecer |
| Texto | caracteres especiais | digitar |
| Mapa REM | signos | interpretar |

Mesma família etimológica (*signum*) em **signo** e **sinal** — sentidos diferentes no painel. Filtrar.

## No teclado × no REM

| Tecla / caractere | Uso comum | No REM |
| --- | --- | --- |
| `*` | curinga, nota, multiplicar | família M* / nota M8 — [inspeção](letra-m-asterisco.html) |
| `=` | igualdade | **N=1** (método, não “nível”) |
| `.` | decimal / fim | **M4.1** (submódulo) |
| `-` / `·` | traço / meio-ponto | separador no lede do painel |
| `/` | caminho, divisão | URLs `pesquisas/…` |
| `#` | hashtag, âncora | id de seção (`#m4`, `#m8`) |
| `@` | menção | fora do protocolo; não é módulo |
| `!` `?` | ênfase / pergunta | tom da frase — unir ou afastar |
| `<>` `{}` `[]` | código | HTML/JS do painel — não digitar no diário como ritual |

Caractere especial **não** é módulo. Vira signo só quando o mapa atribui sentido (ex.: `*` = curinga da série M).

---

## Por que inspecionar estas palavras

1. **Homônimos perigosos:** “sinais” (gesto) ≠ “sinais do teclado”.  
2. **Higiene mental:** limpar a confusão tecla → feitiço.  
3. **Diário:** digitar caracteres; marcar **signos** concretos (M2, não `***`).  
4. **Cultivo:** dúvida sobre uma tecla/palavra vira semente — sem inventar módulo.
