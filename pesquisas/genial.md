# genial

Inspeção + tradução. 2026-08-20.

| Peça | Sentido |
| --- | --- |
| genial | de génio; “isso é genial” |
| genius | génio (nome); em inglês também adjetivo informal |
| brilliant | brilhante — o elogio mais próximo |
| da hora / cool | um degrau mais solto: [da hora](da-hora.html) |
