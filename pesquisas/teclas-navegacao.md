# Home · PgUp · PgDn · End · Ins · Del

Documento de leitura. Inspeção do bloco de teclas.  
Data: 2026-08-03.

---

## O que é

Seis teclas. Bloco entre as letras e o teclado numérico (layout PC clássico).

IBM as chamou, no anúncio do Model M (1985/86), de **screen control** / **function control** — controle de tela e de edição. O povo chama de *nav cluster*.

| Tecla | Ação clássica |
| --- | --- |
| **Home** | Ir ao começo (linha / documento) |
| **End** | Ir ao fim |
| **Page Up** | Subir uma página |
| **Page Down** | Descer uma página |
| **Insert** | Alternar inserir / sobrescrever; atalhos CUA (copiar/colar) |
| **Delete** | Apagar o que está *na frente* do cursor |

---

## Origem

No PC/XT antigo, várias dessas funções moravam no **numpad** (Num Lock desligado).  
No **IBM Enhanced Keyboard (Model M)**, ganharam casa própria — bloco 2×3 acima das setas. Layout que virou padrão mundial.

Antes: compacto no numérico. Depois: navegação sem alternar Num Lock.

## Quebra uma a uma

| Tecla | Imagem |
| --- | --- |
| **Home** | Casa. Voltar à base. Começo da linha. |
| **End** | Fim da linha / do trecho. Fechar o trecho. |
| **PgUp** | Página para cima — memória recente sobe |
| **PgDn** | Página para baixo — o que ainda vem |
| **Ins** | Inserir sem apagar o que já está (ou sobrescrever, se alternado) |
| **Del** | Cortar o que está à frente — limpar caminho |

**Backspace** apaga para trás. **Delete** apaga para a frente. Dois sentidos de higiene.

---

## Por que importa no REM

1. **Home** — voltar ao painel, aos [Sinais](sinais.html), à base.
2. **PgUp / PgDn** — folhear o [diário](diario-rem.html) sem se perder no scroll infinito.
3. **End** — saber onde o trecho fecha; não carregar a página inteira na cabeça.
4. **Ins** — plantar ideia ([cultivo](cultivo-ideias.html)) sem sobrescrever a semente anterior.
5. **Del** — [higiene mental](higiene-mental.html) / [esqueceremos](esqueceremos.html): apagar o excesso *na frente*, com escolha.

Sinais são palavras. Estas teclas são **gestos** de navegação e corte.

## Dois lados

| Lado | Sentido |
| --- | --- |
| **Útil** | Mover-se no texto e na vida em saltos curtos |
| **Ruim** | Delete sem olhar; Insert esquecido em modo sobrescrever |
| **Laptop** | Muitas vezes somem ou viram Fn+seta — o gesto ainda existe |

---

## Resumo para reler

**Home / End** = começo e fim.  
**PgUp / PgDn** = página a página.  
**Ins / Del** = meter ou tirar.  

Bloco IBM: controlar a tela sem perder o chão. No REM: voltar à base, folhear com calma, inserir semente, apagar excesso.
