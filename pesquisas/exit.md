# Exit

- **Forma:** inglês (PT: *saída* · *sair*)
- **Quer dizer:** caminho para fora; deixar lugar / estado / programa
- **Origem:** latim *exire* — ir para fora

## Três exits

| Tipo | Leitura |
| --- | --- |
| Placa | Rota de fuga · “por aqui” |
| Comando | Encerrar a sessão |
| Peito | Sair da couraça — dose ou fuga |

## No REM

- Higiene: freio útil vs abandono
- Sinais: peito pede saída
- Medo de seguir sonhos: exit do medo ≠ exit do sonho
- Diário: frente, fundos, ou só desligar?

## Dois lados

| Lado | Leitura |
| --- | --- |
| Saída limpa | Limiar · ar |
| Fuga | Porta batendo |
| Enter | Exit = enter de outra sala |
| REM | Passagem — ou desligou? |
