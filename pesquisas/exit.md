# Exit

Documento de leitura. Inspeção da palavra.  
Data: 2026-08-03.

---

## O que a palavra é

**Exit** — saída. Ir para fora. Fechar o processo. Porta marcada.

Em português: *saída* · *sair* · *encerrar*. A placa vermelha nos prédios costuma trazer a palavra em inglês mesmo.

---

## Origem

Latim *exīre*: **ex-** (para fora) + **īre** (ir).

Na cena do teatro (séc. XV–XVI): direção de palco — *exit* = “ele/ela sai”.  
Plural: *exeunt* = “eles saem”.

Depois: a **partida**, a **porta**, o **ato de sair**. Verbo em inglês veio do substantivo.

| Camada | Sentido |
| --- | --- |
| Teatro | Personagem deixa a cena |
| Prédio / estrada | Caminho para fora |
| Computador | Encerrar programa / shell (`exit`) |
| Código | `process.exit(1)` — sair com status de erro |

Neste repo, o `npm test` chama `process.exit(1)` se faltar arquivo — **exit** do teste = “não está ok”.

## Primos

| Palavra | Relação |
| --- | --- |
| **Enter** | Antônimo de movimento — entrar |
| **Quit** | Desistir / fechar (mais “largar”) |
| **Esc** | Escape — sair do modo, não necessariamente do programa |
| **End** | Fim do trecho (tecla); exit é ir embora |
| **OK** | Fechar o loop sem sair do mundo |

---

## Por que a palavra importa

1. **Toda casa precisa de saída** — medo sem porta vira redoma.
2. **Exit não é falha** — no teatro é parte do roteiro; no REM, sair da ruminação também.
3. **Status** — em código, exit 0 = ok; exit ≠ 0 = algo quebrou. Nomear o fim com número.

Sinais são palavras. Esta marca a **porta**, não o abandono.

---

## Dois lados

| Lado | Sentido |
| --- | --- |
| **Útil** | Saber onde fica a saída · encerrar com escolha · pausar o app |
| **Ruim** | Exit de pânico · fechar sem salvar (sem commit) · sumir sem aviso |
| **Higiene** | Sair da tela · Win+L · Pause — exit suave do excesso |

---

## Resumo para reler

**Exit** = ir para fora (*ex* + *ire*).  
Nasceu no palco. Virou porta, comando, código.  
No REM: a saída existe — usar sem culpar o “demo”.
