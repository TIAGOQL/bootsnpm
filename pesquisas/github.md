# GitHub

Inspeção. 2026-08-04.

## O que é

Plataforma para guardar e colaborar em código com **Git**. Repositórios, issues, pull requests, Actions (CI), **Pages** (site estático).

- **Fundação:** 2008 (San Francisco)  
- **Fundadores:** Tom Preston-Werner, Chris Wanstrath, P. J. Hyett, Scott Chacon  
- **Desde 2018:** subsidiária da **Microsoft** (aquisição ~US$ 7,5 bi)  

Site: https://github.com
