Module.load

at Module.load (node:internal/modules/cjs/loader:…) — o carregador, não o vilão.

O que é: linha de stack trace do Node.js. Quando um require() falha (ou um script quebra ao carregar), o runtime mostra onde estava: o carregador CommonJS em node:internal/modules/cjs/loader. O número (1577:32 ou outro) é linha:coluna nessa versão do Node — muda entre 20 e 22.

Ler o erro: a causa costuma estar na mensagem (Cannot find module, typo, path) ou nas linhas acima do stack (o seu arquivo). Module.load é o porteiro que tentou abrir a porta.

No Painel REM: npm test, node --check e npm start passam pelo Node — aí essa linha pode aparecer. No navegador, Diário e Cultivo usam <script type="module"> (ESM) e localStorage. O visitante do GitHub Pages não executa Module.load CJS. O peito do N=1 não viaja por esse loader.
