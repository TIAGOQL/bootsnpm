# Trancar

- **Forma:** verbo · infinitivo
- **Quer dizer:** fechar com tranca / chave; impedir passagem
- **Vizinha:** maçaneta (girar / mola) — trancar é o passo a mais

## Origem

De *tranca* — barra / ferrolho. O verbo: pôr a barra no vão.

## Trancar × maçaneta

| Peça | Gesto |
| --- | --- |
| Maçaneta | Gira · mola fecha |
| Trancar | Chave / ferrolho · decisão de não voltar fácil |

## No REM

- Higiene: limite (dose) ou couraça (muro)?
- Sinais: peito no clique da chave
- Diário: o que tranquei — porta, conversa, peito?
- Leite derramado: trancar o que caiu não recolhe

## Dois lados

| Lado | Leitura |
| --- | --- |
| Limite | “Agora não” · ainda respira |
| Muro | Sem saída · ar cortado |
| Chave | Ainda dá para abrir? |
| REM | Protegeu — ou só fechou? |
