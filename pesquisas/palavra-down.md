# down → para baixo / ao longo

Inspeção de palavra · vida. 2026-08-20.

## Forma

- **Inglês:** down
- **Português:** para baixo / ao longo
- **Lede:** Ao longo. Ou para baixo.

## Quer dizer

para baixo, ao longo de. Cruising down = seguindo pela. Não é tristeza (feeling down) aqui.
