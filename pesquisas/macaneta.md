# Maçaneta

- **Forma:** substantivo feminino (também: *maçanete* — forma pedida)
- **Quer dizer:** peça da porta que a mão gira / puxa
- **Tese:** fecha por mola — **colocada errada**; no REM deve **manter a porta aberta**

## Origem

De *maçã* + *-eta* — pomo redondo como maçã pequena. Ponto onde a mão decide passagem.

## Por que fecha

| Camada | Efeito |
| --- | --- |
| Mola / fecho | Soltou → lingueta volta → porta fecha |
| Costume | “Segurar” = trancar, encerrar |
| Peito | Fuga · fim de conversa |

## Colocada errada

Se a função REM é **manter aberta** (conversa, ar, entrada), a mola-padrão está invertida. Não é só metal — é o hábito de deixar o batente vencer.

## No REM

- Higiene: fechar sem dose = couraça
- Sinais: mão na maçaneta — fuga ou abertura?
- Diário: manteve aberto — ou só bateu?
- Leite derramado: não trancar o que já caiu

## Dois lados

| Lado | Leitura |
| --- | --- |
| Mola | Fecha sozinha |
| Cunha | Segura aberta |
| Colocada errada | Função invertida no peito |
| Maçanete | Forma pedida — mesma peça |
| REM | Abriu e manteve — ou só fechou? |
