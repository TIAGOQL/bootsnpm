Conta · Google · Apple

Três palavras, um gesto: dizer quem está neste aparelho — sem inventar senha nova.

Fio: porta · provedor · sessão só aqui.

Relação (trio):
1. Conta — a porta do painel: entrar / cadastro / sair
2. Google — provedor · Identity Services · botão oficial
3. Apple — provedor · Sign in with Apple · Services ID

Como encaixa: Conta é o lugar. Google e Apple são caminhos até a mesma sessão (rem-auth-v1). Cadastro = entrada: a primeira vez cria a marca; as outras reconhecem. Sem nuvem do diário — ver dados pessoais.

Vizinhos no guia: GitHub guarda o código (público); Conta marca a pessoa só no navegador. Module.load carrega módulo pelo nome; Conta carrega identidade pelo provedor. Anonymous some o nome; aqui o nome (ou e-mail) fica local, sob seu controle.

No REM: perto do diário (backup JSON) e da higiene — limpar excesso de conta se apertar. Guia: guia de palavras.
