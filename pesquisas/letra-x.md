# letra X

Inspeção + tradução. 2026-08-20.

**X** → **xis**. O nome novo da rede (antes Twitter) *é* essa letra.

## A letra

Vigésima quarta do alfabeto. Cruza. Marca. Não é palavra.

| Peça | Sentido |
| --- | --- |
| X / xis | a letra, em português |
| nome novo | a rede passou a chamar-se X (2023) |
| incógnita | *x* = o que ainda não se sabe |
| ex | soa perto; não é o nome oficial |

## Relação com o nome novo

Trocaram um nome-palavra (Twitter, o passarinho) por uma letra. O nome novo não descreve: *é* o sinal. SpaceX, x.com — o mesmo traço noutros nomes. Esta página inspeciona o xis, não o feed.
