# Bitter Sweet Symphony — sinfonia agridoce

Inspeção + tradução. 2026-08-20.

The Verve, *Urban Hymns* (1997). Richard Ashcroft. Clipe: o vídeo que chegou no painel. Na mix: a faixa seguinte é [Wonderwall](wonderwall.html).

## Título

| Inglês | Português |
| --- | --- |
| bitter | amargo |
| sweet | doce |
| symphony | sinfonia |
| **Bitter Sweet Symphony** | **sinfonia agridoce** |

Agridoce = os dois no mesmo gole. Esta vida.

## Frases (sentido)

Não é letra inteira — é o peito das linhas:

| Inglês | Português |
| --- | --- |

| trying to make ends meet | tentando fazer as pontas se encontrarem (pagar as contas) |
| you’re a slave to the money, then you die | você é escravo do dinheiro, depois morre |
| the only road I’ve ever been down | a única estrada que já andei |
| where all the veins meet | onde todas as veias se encontram |
| I can change | eu posso mudar |
| I’m here in my mould | estou aqui no meu molde |
| a million different people from one day to the next | um milhão de pessoas diferentes de um dia para o outro |
| I can’t change my mould | não consigo mudar meu molde |
| I’ve never prayed, but tonight I’m on my knees | nunca rezei, mas hoje estou de joelhos |
| sounds that recognize the pain in me | sons que reconhecem a dor em mim |
| let the melody shine, let it cleanse my mind | deixa a melodia brilhar, deixa ela limpar a mente |
| I feel free now | agora me sinto livre |

**Nó:** posso mudar / não saio do molde. Os dois no refrão.
