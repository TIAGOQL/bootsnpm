# M e *

Inspeção de signos. 2026-08-04.

---

## Letra M

**Forma:** M · m  
**Nome (PT):** eme  
**No alfabeto:** 13ª letra

**Origem:** do fenício *mem* (água) → grego *mu* (Μ/μ) → latino M. A forma antiga lembrava ondas.

**No Painel REM:** **M** = **módulo**. Não é “milagre”, “medicamento” nem “maconha” no rótulo do mapa.

| Código | Nome |
| --- | --- |
| M0 | Higiene mental |
| M1 | Movimento |
| M2 | Respiração |
| M3 | Sono |
| M4 | Nutrição |
| M4.1 | Sementinha |
| M5 | Intestino |
| M6 | Vínculo |
| M7 | Cessar fumo |
| M8 | Farmácia (só mapa clínico) |

A letra segura a série. O número (e o ponto, em M4.1) diz **qual** peça do stack.

---

## Signo *

**Não é número.** É tipografia: asterisco (do grego *asteriskos*, “estrelinha”).

No teclado costuma ficar no mesmo jogo dos números (`Shift`+8 em muitos layouts) — daí a confusão “número *”.

### O que o * faz

| Uso | Sentido |
| --- | --- |
| **Curinga** | “qualquer um” — em código, `M*` pode ler-se como “todos os módulos M…” |
| **Nota de rodapé** | “* ver abaixo” — apontar sem abrir parágrafo |
| **Ênfase** | em Markdown, `*itálico*` / `**negrito**` |
| **Multiplicação** | em matemática / programação: `2 * 3` |
| **Obrigatório** | formulários: campo * |

**No REM:** o * lembra que o mapa é uma **família** (M0…M8), não um único botão. Também lembra nota: M8 é asterisco clínico — “existe no mapa, não no diário caseiro”.

---

## M + * juntos

**M\*** = a série modular inteira: higiene → movimento → … → farmácia-mapa.

Ler assim:

1. **M** — estamos em módulo (peça nomeada).  
2. **número** — qual peça (0–8; 4.1).  
3. **\*** — quando a pergunta for “e os outros?”: o curinga da família, não um módulo novo.

Não inventar **M\*** como código no diário. Marcar M1, M2… um de cada vez.

---

## Por que importa

- Sinais são palavras e também **letras e signos**.  
- Confundir M com “remédio” empurra para M8 cedo demais.  
- Confundir * com número atrapalha a leitura do mapa.  
- N=1 pede clareza: um módulo, uma métrica — o * fica para “a família existe”.
