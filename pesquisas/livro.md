# Livro

- **Forma:** substantivo masculino
- **Quer dizer:** folhas encadernadas; obra; também registro
- **Antônimo útil:** página solta · oralidade pura · tela sem fim

## Origem

Latim *liber* — livro; também casca onde se escrevia. Suporte que guarda a fala.

## No REM

- Diário = livro do N=1
- Cultivo: ideias viram páginas no Git
- Esqueceremos: o livro segura o que não quer cair
- Protocolo: uma página, um dia — não a estante inteira
