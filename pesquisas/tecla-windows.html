Tecla Windows (Janela)

O logo de janela. Porta de casa do sistema — não a casa inteira.

Onde: entre Ctrl e Alt (muitos PCs · dois lados da barra de espaço).
Nomes: Windows · Win · Janela · Start · Super (Linux) · ⊞
Nascimento: 1994 (Natural Keyboard) · 1995 (Iniciar no Windows 95)

Primo: ⌘ Command no Mac. Sem a tecla: Ctrl+Esc ainda abre o Iniciar. Vizinha: tecla Menu (☰) — contexto, como o botão direito.

Por que importa no REM: a janela é moldura. Win = porta de casa do SO — voltar ao painel, não ficar preso num app. Win+D limpa a pilha (Sinais). Win+L trava e respira (M0).

Gestos curtos

Win
Menu Iniciar / launcher — porta de casa.
Win+D
Desktop limpo. Ver o chão debaixo das janelas.
Win+L
Travar a sessão. Pausa sem fechar tudo.
Win+E / Tab
Arquivos · visão de tarefas — mapear sem se perder.
Super
No Linux, a mesma tecla: overview / atalhos da casa.
