inspeção de palavra

Markdown

Marca + texto + arquivo .md. Escrita leve que o Git guarda.

Forma: nome da linguagem / do arquivo
Quer dizer: texto quase normal, com poucos sinais, que vira página
Extensão: .md
Vizinho no painel: HTML — a vitrine; o .md é o núcleo

Origem: John Gruber, 2004. Mark = marcar · down = reduzir a marcação. Menos código que HTML; ainda legível como caderno.

Por que importa no REM: cultivo permanente e pesquisas-núcleo vivem em Markdown. Plantar ideia = escrever .md. Virar atalho no painel = HTML. Ver o Cultivo e o guia.

Sinais básicos

# Título
Título grande. ## = subtítulo.
**negrito**
Destaque. *itálico* = ênfase leve.
- item
Lista. Um traço por linha.
[texto](url)
Link. No cultivo: liga a módulo ou página.

Dois lados

Bom
Leve, legível, versionável no Git — língua do canteiro.
Ruim
Achar que o .md sozinho é a página do site. No painel, o atalho é HTML.
