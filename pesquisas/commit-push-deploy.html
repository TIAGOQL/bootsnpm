inspeção de verbos

Commit · Push · Deploy

Gravar. Empurrar. Desdobrar no ar. Ordem importa.

Frase: commit · push · deploy.
Quer dizer: salvar no histórico → enviar ao remoto → publicar o site.

Neste repo: commit na branch → push → (PR) → main → Actions (pages.yml) copia HTML/JS/CSS e cultivo para o GitHub Pages. CI (ci.yml) roda npm test antes da confiança.

Uma vez: Settings → Pages → Source: GitHub Actions. Sem isso o deploy falha.

Por que importa no REM: commit = marcar no diário; push = tirar do aparelho; deploy = tornar visível. LocalStorage do diário não vai no deploy — só o código e as sementes do Git.

Três verbos

Commit
Latim committere — confiar. Pacote local + mensagem.
Push
Empurrar ao origin. Sem push, o mundo não vê.
Deploy
Desdobrar em campo. Aqui: Pages a partir de main.
Falha comum
Pages ainda em “Deploy from branch” — trocar para Actions.
