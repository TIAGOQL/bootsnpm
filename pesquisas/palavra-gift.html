1. Presente — oferecer, receber, leveza
2. Dom — talento natural — pode aquecer ou virar chicote (“tem que”)

Não é: git / GitHub — outra palavra, outro mundo.

No REM: se for presente → s2 ou bom dia, vida. Se for dom → filtrar no peito, como em Filho de Deus (sem cobrança). Hub: hub tradução.
