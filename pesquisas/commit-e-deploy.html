Commit e deploy

Marcar. Depois publicar. Não é a mesma coisa.

Commit: do inglês to commit — comprometer, entregar, registrar.
No Git: um ponto no histórico. Mudança + mensagem. Fica no ramo. Ainda não é o site.

Deploy: do inglês to deploy — colocar em posição, enviar ao campo.
Aqui: publicar o painel. Em main, o Actions sobe o Pages.

Ordem: commit → push → deploy.
Sem commit, não há o que publicar. Sem Pages = GitHub Actions, o deploy falha.

No REM: commit perto do Diário — marcar o que não quer cair fora. Deploy é o outro ver. Se a cabeça pesou: Sinais — um passo; deploy depois. Perto de esqueceremos: commit segura; esquecer o excesso limpa.

Uma vez: Settings → Pages → Source: GitHub Actions.
