Sobre nós

Quem planta. O que o Painel REM é hoje. Sem empresa, sem clínica, sem discurso de time.

Quem planta: O Engenheiro Arquiteto — GitHub TIAGOQL. Uma pessoa. N=1. Constrói (engenheiro) e desenha o lugar (arquiteto). O nome é posição, não diploma.

O “nós”: não é equipe de marketing. É o plural do peito — esses somos nós filhos do sol. Une sem apagar o N=1: cada um ainda marca o próprio dia no diário.

O que é (revisão 2026-08-20): Painel REM, nível 4. Site estático de Relaxamento Endocanabinoide Modular. Pesquisa pessoal com protocolo, mapa e cultivo. Não é app médico, não é clínica, não é rede social, não é loja.

O que o projeto tem hoje

Agora — se a cabeça pesou: Sinais (água · sol · peito · som · marca · para). Base: M0 higiene mental. Quando martela: medo de seguir sonhos.

Núcleo N=1 — Protocolo (4 semanas, no máximo dois módulos novos por vez) · Diário (histórico + export JSON, só no aparelho) · Tônus · Cultivo (canteiro local + ideias no Git).

Mapa REM — módulos M0–M8 + M4.1 Sementinha. SEC = núcleo · endocanabinoidoma = bairro. Meta: tônus que o corpo produz, sem depender da fumaça. M8 só mapa clínico.

Biblioteca — inspeções de palavra e cadeia peito / luz (Filho de Deus · Sun · filhodosol · s2 · Bom dia, vida). Stack Node traduzido. Homenagem reservada a Paulinho o Loko.
