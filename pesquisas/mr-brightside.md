## Frases (sentido)

Não é letra inteira — é o peito das linhas:

| Inglês | Português |
| --- | --- |
| coming out of my cage | saindo da minha gaiola |
| I’ve been doing just fine | eu tenho estado bem (máscara) |
| it started out with a kiss / it was only a kiss | começou com um beijo / era só um beijo |
| how did it end up like this | como é que acabou assim |
| jealousy | ciúme |
| open up my eager eyes | abrir os meus olhos ávidos |
| ’cause I’m Mr. Brightside | porque eu sou o Mr. Brightside |

**Nó:** viu demais. Por fora está bem. O nome que ele se dá é o brilho. O peito é o ciúme.
