load → carregar

Carregar — trazer o arquivo para a memória.

Tradução: carregar, carregar na memória.

No Node: Module.load / _load lê o arquivo, compila e executa. Se o caminho não existe, falha antes ou durante.

No REM: o navegador “carrega” a página e os script type=module. O visitante não usa este load CJS — só quem roda Node no terminal.
