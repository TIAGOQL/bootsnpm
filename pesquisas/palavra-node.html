node → Node (runtime)

Node — o programa que roda JavaScript fora do browser.

Tradução: em português costuma ficar Node (nome próprio). Em inglês node também é “nó”; aqui é o runtime Node.js.

No stack: prefixo node:internal/… = código dentro do Node, não do seu projeto.

No REM: CI e npm test / npm start usam Node. O site no Pages é estático — o visitante não precisa de Node.
