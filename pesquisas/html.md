## O que a palavra é

**HTML** é uma **sigla** (substantivo).

Quer dizer: **HyperText Markup Language** — linguagem de marcação de hipertexto.

Em português curto: a língua das **páginas** que o navegador mostra.

Extensão de arquivo: **`.html`**.

Par no painel: **Markdown (`.md`)** — o núcleo; o HTML é a **vitrine**.

---

## Origem

Criado por **Tim Berners-Lee** (início dos anos 1990) pra World Wide Web.

Quebra da sigla:

| Parte | Significado |
| --- | --- |
| **HyperText** | texto com links (pulos pra outros textos) |
| **Markup** | marcação (rótulos em volta do conteúdo) |
| **Language** | linguagem (regras combinadas) |

A imagem: você **marca** o texto (`<h1>`, `<p>`, `<a>`) e o navegador **desenha** a página.

---

## Sinais básicos (o suficiente)

| Você escreve | Vira |
| --- | --- |
| `<h1>…</h1>` | Título |
| `<p>…</p>` | Parágrafo |
| `<strong>…</strong>` | Negrito / ênfase |
| `<a href="…">…</a>` | Link |
| `<img src="…" alt="…">` | Imagem |

Não precisa decorar tudo. No painel, o HTML já está pronto nas páginas de `pesquisas/` e no `index.html`.

---

## Por que a palavra importa

1. **É a vitrine** — o que você abre no navegador é HTML, não o `.md` cru.
2. **Carrega o atalho** — cards do painel, “← Painel”, notas no rodapé.
3. **Convive com o núcleo** — escrever ideia = Markdown; publicar no painel = HTML.

Regra do projeto: atalho no painel aponta pro **`.html`**.

---

## O bom e o ruim

| Lado | Sentido |
| --- | --- |
| **Bom** | Página legível, links, tipografia do painel, um clique |
| **Ruim** | Achar que HTML é o único lugar da ideia; esquecer o `.md` de estudo |

---

## Resumo para reler

**HTML** é importante porque junta três coisas:

- **marcação** (rótulos)
- **página** (o que o navegador mostra)
- **vitrine** (par do núcleo `.md`)

É a língua da tela — depois da ideia, depois do Markdown.
